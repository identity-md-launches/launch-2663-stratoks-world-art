# Phase 2A model selection and scientific scope

This release implements **an independent, reduced, nonspiking Drosophila mushroom-body-inspired associative circuit**. It does not implement a whole fly brain, a connectome simulation, consciousness, or a biologically validated animal. No fly circuit is claimed to encode wallets, mating eligibility, construction or game identities.

## Equations and fixed parameters

Implementation: `server/src/mushroom.js`, `MB_VERSION=1`; brain interface 1. All constants are release-pinned source, not remotely tunable. Creature/world configuration and source checksums are recorded with evidence.

1. Clamp input channels `x_j` to [0,1]. There are **36 PN-like channels**: 12 existing game features; 16 one-hot 4×4 spatial bins; four local target cues (food, fire, storm, gifted food); hunger, satiety, energy, fatigue. The duplicated internal-need channels intentionally affect competitive coding. Remembered food location is game memory, not remote perception.
2. For each of **128 KC-like units**, draw **6 distinct** PN indices once from the creature's deterministic projection RNG. `z_i = sum(x_j for j in P_i)`. Global inhibition selects the **8 greatest** positive `z_i` (6.25% sparsity), resolving ties by unit index. Binary activity is `k_i=1` for winners, else 0. This top-k operation is an engineering surrogate for inhibitory sparsification, not a simulated APL neuron.
3. Each of 11 game actions has two 128-value arrays `W+` and `W−`, initially zero. `V_a = sum_i k_i (W+_ai − W−_ai) / sum_i k_i`, or zero with no activity. `score_a = innate_game_utility_a + 2.5 V_a + wallet_adjustment_a`. The fixed prior uses the original hand-designed coefficients and personality offsets, **not archived learned linear weights**. For separate EAT targets, encode each candidate's location/cues. Other actions encode the creature's current location.
4. At actual action completion, reward `r=clip(Δhunger/25 + Δenergy/40 + Δhealth/20 + task_bonus − 0.002 duration + outcome_adjustments, −2,2)` is the existing game's reward. The active set stored at action start is its eligibility trace. For each active synapse: `W+ ← clip(W+ + .18(max(r,0) − W+),0,2)`; `W− ← clip(W− + .18(max(−r,0) − W−),0,2)`. Other synapses stay unchanged. An opposite outcome weakens the formerly favored channel while strengthening the opposing channel, allowing reversal.
5. Softmax uses the existing world temperature (default **0.35**) and one local Mulberry32 draw per model selection. `mb.rng` persists. Initialization seed is FNV-1a of `stratoks:mb-v1:<world seed>:<creature ID>`; projection generation never consumes the global world RNG. Navigation, ecology and births keep their existing global RNG.

This is a nonlinear sparse associative value learner, not the old linear model renamed. It remains a one-step engineered reinforcement system. Positive/negative channel updates are a dopamine-inspired phenomenological rule, **not** a fitted account of specific transmitter receptors, KC→MBON depression, or the sign of any identified synapse. The reward is a shaped game scalar, not a measured dopamine concentration.

## Modeled and omitted mechanisms

Modeled at the functional abstraction level: sensory convergence/expansion, sparse competitive coding, input-specific output plasticity, signed reinforcement, action-bound eligibility, internal-need modulation, stochastic valence-biased action selection and reversible association.

Omitted: connectome neuron identity, compartment/neuron-type mapping, spike timing, dendrites, conductances, transmitter-specific physiology, dynamic APL inhibition, recurrent MBON/DAN feedback, realistic eligibility time constants, consolidation, sleep, sensory organs, optic flow, body biomechanics, planning, second-order learning and social transmission of circuit weights. No KC count or learning rate is claimed to be biologically fitted. No reduction mapping is provided because **no connectome-derived wiring is used**.

## Game abstractions remain separate

The fixed action repertoire, resource costs, navigation, housing, relationships, adult eligibility, fertility, births/deaths and disasters retain their application semantics. Personality modifies fixed utilities. New offspring retain the existing legacy inheritance algorithm, but receive an independent new circuit; acquired KC associations are not genetically inherited. Wallet addresses remain authenticated application accounts with the existing helpful/harmful memory, bounds and authorization. Wallet valence adds ±3v to approach/avoid scores; it is not a fly representation of identity.

Hard emergency actions are marked `reflex`. Hunger-driven search without known food is marked `rule`. Softmax selections are marked `model`. These labels describe selection, not whether a forced exposure can subsequently teach an association. Reward history separately records whether plasticity actually happened. Frozen mode freezes **circuit** plasticity; wallet opinions keep their existing independent `LEARNING` policy. `LEARNING=0` freezes both forms of learning. Catch-up never learns.

## Licensing conclusion and limits

No restricted scientific dataset is needed by the selected circuit. MIT comparison-code notices accompany the retained source files. The GPL comparison has metadata only. Existing application/art/font/wallet-brand notices remain in `docs/licenses/` and the verified archive. No new trained/scientific assets are added. This is a source-and-data inventory, not a legal opinion: there is no general grant here to re-use FlyWire data commercially, and this review does not relicense the recovered backend (the archive contains no standalone backend license). The owner should settle backend distribution rights before public redistribution; this assignment does not infer those rights from the client's MIT notice.
