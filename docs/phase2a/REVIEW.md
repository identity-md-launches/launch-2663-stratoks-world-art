# Component review against this release

This is the implementation author's adversarial review plus executable checks. It is **not an independent external sign-off**. A separate reviewer and full-client release integration remain required before production activation.

| Concern | Evidence / outcome |
|---|---|
| Is this the recovered baseline? | Verified named ZIP before extraction; retained complete archive. Original backend fixture modules and unchanged client build are pinned in the inventory. No old GitHub main checkout used. |
| Decorative brain versus causal control | Actual `decide()` candidates are scored by `controller.js` using candidate-specific sparse codes; eligibility is captured in `startAct()` and actual outcomes train it in `endAct()`. The targeted world test trains spatial associations, observes selected food targets and executes the action, decreasing food and hunger. |
| Scripted avoidance mistaken for learning | Synthetic conditioning bypasses emergency rules and has equal innate target scores, random counterbalanced reward location, frozen and ablated controls, post-training readout lesion, novel trial draws and no-update heldout evaluation. Real decisions carry `reflex`, `rule` or `model`. Passing a fire reflex is never counted as learned avoidance. |
| Preserved legacy behavior | Direct 4,000-tick differential test against actual recovered World modules, including ordinary resource use, construction and reproduction. Only additive brain/inspection/action metadata is removed for that comparison. No legacy RNG draws were added. |
| Migration erases learning | Schema migration adds metadata only. Legacy weights stay in their original field. New circuit starts at zero rather than pretending a translation. Unknown active versions fail. |
| Restart/reseed/rollback | Snapshot contains projection, arrays, local RNG and pending eligibility. Tests compare serialized continuation, restore a real backup, and roll back policy on a copied directory. Compatibility export is loaded by actual recovered server modules and re-opened in the new server without losing the archived circuit. Original backup bytes are checked. |
| Freeze races with pending actions | Captured action mode must match current mode to learn. Frozen mode, LEARNING=false and catch-up prevent neural weight changes. A mode change does not restart/replace the world or cancel its action. |
| Newborns and inherited knowledge | Brain interface version is set at creation, including births. New circuit initialization is deterministic and independent; archived linear inheritance remains unchanged. No biological inheritance claim is made. |
| Nonlocal observations | New-mode social and visitor sensing is radius bounded. Candidate cue sensing checks range; remembered distant food is explicitly game memory and does not reveal its current cues. Existing global construction/fertility feasibility rules remain game rules. |
| Authorization / production isolation | No new writable HTTP/WS route. Existing wallet authentication and intervention rules remain untouched and covered by recovered tests. Inspector uses GET/WS only. Browser conditioning controls mutate local JS state only. Local demo ignores production configuration, binds loopback and uses a fresh temporary directory. |
| Unbounded neural/log state | 128 fixed KC units, two arrays per 11 actions, max 8 eligible winners, one last inspection, 16 reward records. No neural append log or remote service. Existing event/memory/rate bounds remain. |
| License assertions | Separate code and data decisions in MODEL.md; no biological data, trained tensors, GPL model implementation or connectome wiring shipped. MIT comparison notices retained. Recovered backend's missing standalone distribution grant is explicitly unresolved; client MIT does not supply it. |
| Resource claim | Actual service+clients measurements, sampled watchdog and single-core duty cap; Docker profile provided. No claim of an exact cgroup test on this machine, which lacks Docker. Results name source hashes, population changes and payloads. Short throughput/cadence evidence cannot establish indefinite survival or capacity. |
| Browser/public release claim | Static client and functional DOM-scaffold test delivered. The scaffold is clearly identified and uses real HTTP/WS/circuit modules. No real-browser screenshots, IMD public URL or public HTTPS/WSS validation is fabricated. Those checks remain release integration work. |

Defects caught and repaired during implementation: newborn interface metadata changed on reload; old tests assumed schema 2; pending actions could otherwise bypass a later freeze; remote social sensing needed a new-mode bound; reflex/rule reward history needed accurate plasticity/source labels. Persistence testing also exposed signed-zero differences in rounded display telemetry; the continuation assertion now compares the actual JSON representation, preserving exact learned numbers.

Remaining scientific limitations: phenomenological plasticity, synthetic spatial/cue inputs, coarse sparse coding, and shaped game reward are not animal validation. Controlled conditioning success does not establish superior ecological fitness, consciousness or planning. Inspect the full-ecology outcomes and failures independently of the conditioning task.
