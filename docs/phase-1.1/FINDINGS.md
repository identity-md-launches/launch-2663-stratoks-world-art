### Existing tests changed on purpose
* `client-integration.test.js`: save failure now returns **503** `not_durable_retry_same_id` instead of 500, and intervention keys are `actor:id`. The behaviour it checks (a failed save is never acknowledged; a retry is a duplicate once durable) still holds.
* `service.test.js`: a duplicate after restart is checked with the same developer wallet (a different actor is no longer a duplicate, by design). The migration test expects schema 2.
